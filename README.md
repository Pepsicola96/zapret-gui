# ZapretGUI — графический интерфейс для zapret-discord-youtube

Удобный десктоп-интерфейс (CustomTkinter) над проектом
[Flowseal/zapret-discord-youtube](https://github.com/flowseal/zapret-discord-youtube):
запуск/остановка сервиса, выбор стратегий обхода DPI, редактирование списков
доменов, автозагрузка, системный трей и документация. Без каких-либо
вредоносных компонентов — только управление уже установленной сборкой zapret.

## Возможности

| Вкладка | Функции |
|---|---|
| **Dashboard** | Запуск / остановка / перезапуск сервиса, живой лог, индикатор состояния, проверка доступности Discord/YouTube |
| **Profiles** | Выбор стратегии обхода (`strategy.list`), пресеты профилей, сохранение конфигурации |
| **Lists** | Редактор списков доменов/IP (`list.txt`, `ip.txt`), импорт/экспорт, валидация строк |
| **Settings** | Путь к папке zapret, тема оформления, язык (RU/EN), автозапуск с системой, запуск свёрнутым, трей |
| **Help** | Встроенная справка, ссылки на оригинальный репозиторий и решение типовых проблем |

Дополнительно: системный трей (pystray), установка/удаление службы Windows,
персистентные настройки в `settings.json`.

## Структура проекта

```
ZapretGUI/

├── settings.json         # хранилище настроек

    ├── dashboard_tab.py
    ├── profiles_tab.py
    ├── lists_tab.py
    ├── settings_tab.py
    └── help_tab.py
```

## Установка и запуск

1. Установите Python 3.10+.
2. Скачайте сборку [zapret-discord-youtube](https://github.com/flowseal/zapret-discord-youtube/releases)
   и распакуйте её в любую папку (например `C:\zapret`).
3. Установите зависимости:

   ```bash
   pip install -r requirements.txt
   ```

4. Запустите интерфейс (желательно от имени администратора,
   так как zapret создаёт сетевые правила):

   ```bash
   python ZapretGUI/main.py
   ```

5. Во вкладке **Settings** укажите путь к распакованной сборке zapret.

## Безопасность

Интерфейс не скачивает и не выполняет произвольный код из сети: он лишь
запускает бинарные файлы уже установленной у вас сборки zapret и редактирует
её текстовые конфиги. Все команды формируются локально из белого списка
стратегий.
